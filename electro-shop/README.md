# نظام إدارة متجر مستلزمات الكهرباء

نظام محلي كامل لإدارة متجر مستلزمات كهرباء في مصر: نقطة بيع، مخزون، مشتريات، مرتجعات، عملاء وموردون، صندوق، تقارير، مستخدمون وصلاحيات، نسخ احتياطي، وسجل تدقيق. الواجهة عربية بالكامل (RTL) والعملة الجنيه المصري.

## المتطلبات

- Node.js إصدار 18 أو أحدث — يُحمَّل من الموقع الرسمي: <https://nodejs.org>
- نظام التشغيل: Windows أو macOS أو Linux
- لا يحتاج اتصالًا بالإنترنت بعد التثبيت — يعمل محليًا بالكامل

## خطوات التثبيت

1. فك ضغط ملف المشروع (ZIP) في مجلد ثابت مثل `C:\electro-shop` على Windows أو `~/electro-shop` على Linux.

2. فتح موجه الأوامر (Terminal أو Command Prompt) داخل مجلد المشروع:
   - على Windows: اضغط على شريط العنوان في مستكشف الملفات واكتب `cmd` ثم Enter.
   - أو استخدم الأمر: `cd C:\electro-shop`

3. تثبيت الاعتماديات (مرة واحدة فقط):

   ```
   npm install
   ```

4. تشغيل النظام:

   ```
   npm start
   ```

5. فتح المتصفح على العنوان:

   <http://127.0.0.1:3000>

## الدخول أول مرة

- اسم المستخدم: `admin`
- كلمة المرور: `admin`
- سيطلب النظام تغيير كلمة المرور فورًا بعد أول دخول — لا تتخطَّ هذه الخطوة.

## التشغيل ببيانات نموذجية (للتجربة)

```
npm run start:sample
```

يزرع هذا الأمر 16 صنفًا كهربائيًا وعملاء وموردين ورصيدًا افتتاحيًا للتجربة. لا يستخدم قاعدة بيانات الإنتاج — بل ملفًا منفصلًا عند تشغيله أول مرة في مجلد `data`.

## الأوامر المتاحة

| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل الخادم |
| `npm run start:sample` | تشغيل ببيانات نموذجية |

## الميزات الرئيسية

- نقطة بيع سريعة: بحث بالاسم أو الباركود، خصم بنود وخصم فاتورة، نقدي أو آجل، حساب الباقي.
- مخزون يعتمد الحركات (لا حقل مخزون قابل للانحراف) مع التكلفة الوسيطة المرجحة تلقائيًا، وسجل تاريخ الأسعار لكل صنف عند أي تغيير.
- منع البيع بأقل من التكلفة وضبط حد أقصى للخصم (قابل للتعديل من الإعدادات).
- حدود ائتمان للعملاء مع منع التجاوز، وتحصيل وسداد مع أثر مباشر على الصندوق.
- مرتجعات مبيعات ومشتريات بحد كمية لا يتجاوز المُباع/المشترى فعليًا.
- صندوق كامل: إيداع، سحب، مصروفات، وسجل تراكمي لكل الحركات.
- تقارير: مبيعات يومية، أرباح، أداء الأصناف، أصناف تحت حد الطلب — كلها قابلة للتصدير CSV (تفتح في Excel العربية بشكل سليم).
- أربعة أدوار جاهزة: مدير النظام، مدير، كاشير، محاسب — بمصفوفة صلاحيات صارمة مطبقة على الخادم.
- نسخ احتياطي بضغطة زر (VACUUM INTO) مع فحص سلامة الملف قبل أي استرجاع.
- سجل تدقيق شامل لكل عملية حساسة.

## استيراد الأصناف من ملف CSV

من شاشة الأصناف — زر «استيراد CSV». الصف الأول عناوين إلزامية `sku` و `name` والبقية اختيارية:

```
sku,name,category,unit,cost_price,sale_price,reorder_level,barcode
CBL-6,كابل نحاس 6 مم,كابلات وأسلاك,roll,4200,4750,4,
```

الوحدات المدعومة: `pcs` قطعة، `box` علبة، `meter` متر، `roll` لفة، `kg` كجم.

## النسخ الاحتياطي والاسترجاع

- من شاشة «النسخ الاحتياطي» — زر «إنشاء نسخة احتياطية الآن» ينشئ ملفًا داخل `data/backups/`.
- الاسترجاع يفحص سلامة الملف أولًا؛ إن كان تالفًا يُرفض ولا يمس البيانات الحالية.
- يُنصح بإعادة تشغيل الخادم بعد الاسترجاع: أوقف الخادم (Ctrl+C) ثم `npm start`.
- انسخ مجلد `data/` بالكامل إلى وسط خارجي من حين لآخر — هذا كل بياناتك.

## استكشاف الأخطاء

- **المنفذ 3000 مستخدم**: أغلق البرنامج الذي يستخدمه أو شغّل بأمر `PORT=3001 npm start` (على Windows: `set PORT=3001` ثم `npm start`).
- **فشل npm install على Windows أحيانًا**: تأكد من تثبيت أدوات البناء لـ better-sqlite3 — غالبًا يعمل مباشرة مع Node 18+.
- **نسيت كلمة مرور admin**: احذف ملف `data/shop.db` ثم شغّل `npm start` — سيعيد إنشاء الحساب الافتراضي (admin/admin) لكن ستُفقد البيانات؛ الأفضل: استرجع آخر نسخة احتياطية قبل الحذف.
- **لا يفتح المتصفح**: العنوان الصحيح <http://127.0.0.1:3000> وليس localhost مع HTTPS.

## القيود المعروفة

- يعمل على جهاز واحد فقط — لا يدعم عدة أجهزة على الشبكة في هذه النسخة.
- لا يوجد HTTPS ولا وصول من خارج الجهاز (عن قصد: نظام محلي).
- الطباعة تعتمد على طباعة المتصفح للصفحة، ولا توجد إيصالات حرارية مخصصة.
- الضريبة تُدعم كنسبة لكل صنف على مستوى البند، وليس نظام ضريبة قيمة مضافة كامل.
